# OpenHarness 使用手册

## 飞书命令手册

在飞书聊天中直接发送以下命令与 OpenHarness 交互。

### 模式切换

每次切换在**下一个新任务**生效，不影响当前正在运行的任务。

| 命令 | 说明 |
|---|---|
| `harness 普通模式` / `harness normal` | 切换到普通模式（单 Agent，适合简单任务） |
| `harness 专家模式` / `harness expert` / `harness swarm` | 切换到专家模式（多 Agent 协作，适合复杂项目） |

也支持加 `mode` 前缀：`harness mode 普通模式`

**模式区别：**

| | 普通模式 | 专家模式 |
|---|---|---|
| Agent 数量 | 1 个全能助手 | PM + Planner + Generator + Evaluator |
| 适用场景 | 简单任务、快速问答 | 完整项目开发 |
| 群聊权限 | 所有人可回复 | 仅任务发起者可回复 |

### 任务控制

| 命令 | 说明 |
|---|---|
| 直接发送任务描述 | 发起新任务（如"写一个 Flask hello world"） |
| `终止` / `停止` / `abort` / `cancel` / `stop` | 终止当前任务 |

> 终止命令不需要 `harness` 前缀，直接发送即可。

### 会话管理

| 命令 | 说明 |
|---|---|
| `harness list` | 列出所有可恢复的历史会话 |
| `harness resume <会话ID>` | 恢复指定会话继续执行 |

> 会话 ID 为 8 位十六进制字符串（如 `a1b2c3d4`），在任务完成或终止时会返回。

### 典型流程

```
用户: harness 普通模式
Bot:  已切换到普通模式 (单 Agent)

用户: 帮我写一个 Todo List 应用
Bot:  🚀 任务已启动 (普通模式): 帮我写一个 Todo List 应用
      [Assistant] 好的，我来帮你...
      ...

用户: 终止
Bot:  ⚠️ 任务已终止
      📋 会话ID（可用于恢复）: a1b2c3d4

用户: harness resume a1b2c3d4
Bot:  🔄 会话已恢复 (ID: a1b2c3d4)
```

## CLI 命令手册

### 基本用法

```bash
# 运行开发任务
python main.py "构建一个带暗色主题的任务管理应用"

# 飞书服务模式
python server.py
```

### 知识管理命令

在启用知识共享后（`config/harness.yaml` 中 `knowledge.enabled: true`），可使用以下命令管理开发经验：

```bash
# 查看同步状态
python main.py knowledge status

# 手动触发同步（推送本地经验 + 拉取共享经验）
python main.py knowledge sync

# 搜索经验
python main.py knowledge search "React 错误处理"
python main.py knowledge search "Docker 部署"
```

### 启动知识服务器

```bash
# 启动中央知识服务器（默认端口 8900）
python -m knowledge_server

# 通过环境变量自定义配置
KNOWLEDGE_SERVER_PORT=9000 python -m knowledge_server
```

### 知识共享配置

1. 在 `config/harness.yaml` 中启用：

```yaml
harness:
  knowledge:
    enabled: true
    server_url: "http://localhost:8900"
    offline_enabled: true
    pull_enabled: true
```

2. 在 `.env` 中配置认证：

```dotenv
KNOWLEDGE_SERVER_API_KEY=your_api_key
KNOWLEDGE_CLIENT_ID=your_client_id
```

### 典型工作流

```
# 1. 启动知识服务器（终端 1）
python -m knowledge_server

# 2. 正常开发（终端 2）
python main.py "构建一个计算器"
# → Swarm 执行完成后自动收集经验并同步到服务器

# 3. 查看同步状态
python main.py knowledge status
# Server: online (http://localhost:8900)
# Queue status: {'synced': 3, 'pending': 0}

# 4. 搜索历史经验
python main.py knowledge search "FastAPI 路由"
# Found 2 results for 'FastAPI 路由':
#   1. [code_pattern] FastAPI 路由分组模式
#   2. [problem_solution] FastAPI 路由参数校验错误修复
```
