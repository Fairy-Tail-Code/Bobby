# 知识服务器架构

## 概述

知识服务器（Knowledge Server）是 OpenHarness 的经验共享基础设施，支持多个 CLI 实例将开发过程中积累的经验（问题解决方案、代码模式、架构决策等）汇聚到中央服务器，实现跨会话、跨用户的知识共享。

## 架构

```
┌─────────────────── CLI 实例 ───────────────────┐
│                                                  │
│  main.py ──> Swarm 执行 ──> ExperienceCollector  │
│                                │                 │
│                          LocalKnowledgeStore      │
│                         (SQLite 离线队列)         │
│                                │                 │
│                          KnowledgeSyncClient      │
│                         (HTTP 推送/拉取)           │
└──────────────────────────────┬───────────────────┘
                               │
                    ┌──────────▼──────────┐
                    │  中央知识服务器        │
                    │  FastAPI + SQLite    │
                    │  FTS5 全文检索        │
                    └─────────────────────┘
```

## 组件说明

### 中央知识服务器 (`knowledge_server/`)

| 文件 | 说明 |
|------|------|
| `app.py` | FastAPI 应用工厂 |
| `main.py` | uvicorn 启动入口 |
| `database.py` | SQLite + FTS5 全文索引 |
| `models.py` | Pydantic 数据模型 |
| `routers/auth.py` | API Key 认证 |
| `routers/experiences.py` | 经验 CRUD |
| `routers/sync.py` | 推送/拉取同步 |
| `routers/search.py` | FTS5 全文搜索 |

### 本地经验收集器 (`infrastructure/knowledge/`)

| 文件 | 说明 |
|------|------|
| `collector.py` | 用 LLM 从聊天历史提取结构化经验 |
| `local_store.py` | SQLite 离线队列（服务器不可用时缓存） |
| `sync_client.py` | HTTP 同步客户端 |
| `formatter.py` | 写入本地 memory 文件 |

## 数据模型

### Experience 经验条目

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 服务端分配 |
| title | String | 标题 |
| category | Enum | 经验类别 |
| content | Text | Markdown 正文 |
| tags | JSON | 技术标签 |
| context | JSON | 结构化元数据 |
| source_agent | String | 来源 Agent |
| visibility | String | private / team / public |
| content_hash | String | SHA-256 去重 |

### 经验类别

| 类别 | 说明 |
|------|------|
| problem_solution | Bug 修复、错误解决 |
| code_pattern | 可复用代码模式 |
| agent_decision | Agent 技术决策及原因 |
| architecture | 架构设计决策 |
| pitfall | 踩坑记录和替代方案 |
| user_preference | 用户偏好 |
| config_trick | 配置技巧 |

## API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/v1/health` | GET | 健康检查 |
| `/api/v1/auth/register` | POST | 注册 CLI 客户端 |
| `/api/v1/auth/token` | POST | 验证 API Key |
| `/api/v1/sync/push` | POST | 批量推送经验 |
| `/api/v1/sync/pull` | POST | 增量拉取经验 |
| `/api/v1/experiences` | GET/POST | 经验 CRUD |
| `/api/v1/search?q=` | GET | 全文搜索 |

## 工作流程

1. **Swarm 完成** → 聊天历史可用
2. **ExperienceCollector** → LLM 提取结构化经验
3. **LocalKnowledgeStore** → 写入离线队列
4. **KnowledgeSyncClient.push** → 推送到服务器（失败则排队）
5. **KnowledgeSyncClient.pull** → 拉取共享经验写入本地 memory

## 配置

### 服务端

通过环境变量配置：

```bash
KNOWLEDGE_SERVER_HOST=0.0.0.0
KNOWLEDGE_SERVER_PORT=8900
KNOWLEDGE_SERVER_DB_PATH=./knowledge_server.db
KNOWLEDGE_SERVER_MASTER_KEY=your_master_key
```

### 客户端

在 `config/harness.yaml` 中配置：

```yaml
harness:
  knowledge:
    enabled: false                     # 默认关闭，需显式启用
    server_url: "http://localhost:8900"
    sync_interval_seconds: 300
    offline_enabled: true
    pull_enabled: true
```

在 `.env` 中配置认证：

```dotenv
KNOWLEDGE_SERVER_API_KEY=your_api_key
KNOWLEDGE_CLIENT_ID=your_client_id
```

## 设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 同步模式 | 离线优先 | CLI 无网络时正常工作 |
| 冲突解决 | Last-writer-wins | 经验以追加为主 |
| 去重 | SHA-256 content_hash | 客户端+服务端双重去重 |
| 存储引擎 | SQLite + FTS5 | 零外部依赖 |
| 认证 | API Key | 简单实用 |

## 使用

```bash
# 启动中央服务器
python -m knowledge_server

# CLI 开发（经验自动收集和同步）
python main.py "构建一个计算器"

# 手动管理
python main.py knowledge status
python main.py knowledge sync
python main.py knowledge search "React 错误处理"
```
