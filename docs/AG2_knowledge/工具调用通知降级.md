# 工具调用通知降级

## 适用场景

- AG2 beta network 下，角色会话通过 `MemoryStream.where(ToolCallEvent).subscribe(...)` 监听工具调用。
- 前端会在工具开始执行时发送“正在执行工具”的提示消息。

## 结论

- 这类工具提示属于观测性通知，不应反向决定 beta tool execution 是否成功。
- 订阅回调里如果直接 await 外部网关发送，一旦网关偶发失败，异常会沿 beta stream 传播，最终中断整条 agent turn。

## 落地原则

1. `ToolCallEvent` observer 应视为 best-effort。
2. observer 内部应捕获并记录前端通知异常，不要让异常重新抛回 beta stream。
3. 事件历史写入和工具执行结果必须继续保留，避免“工具已执行但 session 被 toast 打断”。

## 对当前项目的含义

- `orchestration/network_runtime.py` 中的 `_RoleSession._on_tool_call()` 负责这一层隔离。
- 网关自身仍可对普通 `send_text()` 保持原有失败语义；只有 tool-call 提示被降级为不影响主流程。
