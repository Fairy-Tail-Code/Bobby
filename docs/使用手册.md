# OpenHarness 使用手册

## 用户目录

OpenHarness 运行时统一使用用户目录：

- 默认：`~/.openharness/`
- 可选覆盖：环境变量 `OPENHARNESS_HOME`

目录结构：

```text
~/.openharness/
├── .env
├── .env.example
├── config/
│   ├── harness.yaml
│   ├── mcp.yaml
│   └── skill.yaml
├── agents/
│   └── prompts/        # Agent 系统提示词（用户可编辑）
├── session/
├── memory/
├── skills/
└── workspace/
```

## 初始化

```bash
python cli.py install
```

安装程序会：

- 创建 `config`、`agents/prompts`、`mcp`、`session`、`memory`、`skill`、`workspace` 对应的用户目录
- 把默认 `harness.yaml`、`mcp.yaml`、`skill.yaml` 安装到 `~/.openharness/config/`
- 把默认 Agent 提示词（`pm.md`、`planner.md`、`generator.md`、`evaluator.md` 等）安装到 `~/.openharness/agents/prompts/`
- 生成 `~/.openharness/.env.example` 和 `~/.openharness/.env`
- 保持 `session/` 初始为空

## 配置 `.env`

原来如果你把 API Key 写在仓库根目录 `.env`，现在需要改到：

```text
~/.openharness/.env
```

至少需要配置四个角色的 LLM 参数：

```dotenv
PM_MODEL=
PM_BASE_URL=
PM_API_KEY=

PLANNER_MODEL=
PLANNER_BASE_URL=
PLANNER_API_KEY=

GENERATOR_MODEL=
GENERATOR_BASE_URL=
GENERATOR_API_KEY=

EVALUATOR_MODEL=
EVALUATOR_BASE_URL=
EVALUATOR_API_KEY=
```

## 配置 YAML

以下配置文件都在用户目录，不在仓库根目录：

- `~/.openharness/config/harness.yaml`
- `~/.openharness/config/mcp.yaml`
- `~/.openharness/config/skill.yaml`

例如启用知识共享：

```yaml
harness:
  knowledge:
    enabled: true
    server_url: "http://localhost:8900"
```

## 常用命令

```bash
python cli.py run "帮我生成一个 FastAPI 项目"
python cli.py info
python cli.py knowledge status
python cli.py knowledge sync
python cli.py knowledge search "FastAPI 路由"
```

开发态也支持：

```bash
python main.py "帮我生成一个 FastAPI 项目"
python server.py
```

但它们同样读取 `~/.openharness/` 下的配置。

## 会话管理

会话快照保存在：

```text
~/.openharness/session/<timestamp>/snapshot_<session_id>.json
```

恢复和列举会递归扫描该目录结构。

## 工作区

未显式指定工作目录时，内置 MCP 服务默认使用：

```text
~/.openharness/workspace/
```

这样可以避免把运行时文件误写回仓库根目录。
