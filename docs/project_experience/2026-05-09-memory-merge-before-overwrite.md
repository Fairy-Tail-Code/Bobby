# 2026-05-09 记忆合并后写入

## 背景

自动记忆抽取初版已经可以在 session 收尾阶段提炼 durable memory，但落盘策略仍偏简单：

- 抽取结果直接按 `name` 写入
- 虽然同名文件会被覆盖，但不会先读取旧内容做结构化合并
- 当新旧记忆都有效时，容易出现“新内容把旧上下文抹掉”的问题

`cc-haha` 的自动记忆设计更强调复用既有记忆、避免重复和粗暴覆盖，因此这里补齐 merge 语义。

## 本次实现

- 自动抽取命中已有同名 memory 时，先读取旧文档
- 通过独立 merge prompt 生成最终记忆版本
- merge prompt 会保留仍然有效的旧信息，整合新增 durable facts，替换明确过时内容
- 当合并结果与旧内容等价时，跳过写盘，避免无意义刷新文件时间

## 结果

现在自动记忆落盘不再是“抽到什么就直接写什么”，而是：

1. 抽取新记忆候选
2. 查找已有 memory
3. 如存在则合并
4. 仅在内容发生有效变化时写回

这使得记忆系统更接近 `cc-haha` 的“持续演化的文件型知识库”而不是一次次追加或覆盖的碎片笔记。
